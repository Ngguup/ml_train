# House Prices - Advanced Regression Techniques

Решение в: task.ipynb

## Описание решения

1. Загрузил данные и удалил Id, а также признаки, в которых заполнено менее 60% значений.
2. Разделил признаки на числовые и категориальные.
3. Для числовых признаков заполнил пропуски:
   - целочисленные признаки — наиболее частым значением
   - вещественные признаки — средним значением
4. Стандартизировал числовые признаки с помощью StandardScaler.
5. Для заполнения пропущенных категориальных признаков обучил отдельную LogisticRegression на числовых признаках и с её помощью предсказал пропущенные значения.
6. Преобразовал категориальные признаки через OneHotEncoder. В результате получил 266 признаков.
7. В качестве модели использовал LinearRegression.
8. Перед обучением преобразовал целевую переменную с помощью log1p, чтобы уменьшить влияние больших значений цены.
9. Разделил данные на обучающую и валидационную выборки и проверил качество модели. На валидации получил RMSE = 0.1282.
10. Обучил модель на всех доступных обучающих данных.
11. Получил предсказания для тестовой выборки и вернул значения цены из логарифмического масштаба с помощью expm1.
12. Сохранил предсказания в submission.csv.
