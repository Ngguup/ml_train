# Titanic - Machine Learning from Disaster

Решение в: task.ipynb

## Описание решения

1. Загрузил данные и провёл первичный EDA: посмотрел типы признаков, количество пропусков, количество уникальных значений и распределение целевой переменной.
    1. Исследовал Name:
        - разделил Name на Surname и Status
        - посмотрел зависимость выживаемости от Status
        - объединил редкие значения Status в несколько групп
    2. Исследовал Fare:
        - посмотрел распределение Fare и его зависимость от выживаемости
        - по графику определил, с какого значения стоимости вероятность выживания становится больше вероятности смерти
        - добавил бинарный признак Fare>40
    3. Исследовал Sex:
        - посмотрел зависимость выживаемости от пола
        - график показал сильную корреляцию
        - переименовал признак в IsFemale, сделав его бинарным
    4. Исследовал Age:
        - нашёл признаки, при которых распределение Age было разным
        - сгруппировал Age по этим признакам
        - заполнял пропуски средним значением внутри этих групп
        - аналогично Fare выделил дополнительный признак Age<9.22
    5. Исследовал Embarked:
        - т.к. этот признак имел очень мало пропусков, просто заполнил их наиболее часто встречающимся значением
    6. Исследовал Ticket:
        - выделил префикс
        - т.к. одинаковый префикс в датасете мог быть записан по-разному, выделил наиболее часто встречающиеся варианты и заменил их названия на одинаковые.
    7. Удалил оставшиеся ненужные колонки.
2. В качестве модели использовал CatBoostClassifier, т.к. он может обрабатывать категориальные признаки.
3. Гиперпараметры модели подбирал перебором, сравнивая результаты на валидации.
4. После выбора признаков и параметров обучил итоговую модель на обучающей выборке.
5. Получил предсказания для тестовой выборки и сохранил результат в submission.csv.
